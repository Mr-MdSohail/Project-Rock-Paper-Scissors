# Project-Rock-Paper-Scissors

This repository contains two versions of a Rock Paper Scissors game that I built while learning Python.

## Version 1 - Basic Python

Features:

- Play against the computer
- Score tracking
- Input validation
- Multiple rounds

File:

```text
version-1.py
```

## Version 2 - Python + SQLite

Features:

- User profiles
- Database integration
- Persistent score tracking
- Win/Loss/Draw statistics
- Scoreboard

Files:

```text
version-2.py
create_table.sql
```

## Technologies Used

- Python
- SQLite

## Purpose

This project demonstrates my progression from a basic Python game to a database-backed version using SQLite.
